개인정보처리방침

시행일: 2025년 1월 1일  |  최종 수정: 2026년 5월 27일

원시력 테스트의 사진 분석은 사용자의 브라우저 안에서 이루어집니다. 다만 사용자가 직접 '주간 랭킹'에 등록하는 경우에 한해, 해당 사진과 닉네임이 서버에 저장되어 공개 랭킹에 표시되며 다음 주에 자동 삭제됩니다.

1. 수집하는 개인정보 항목

원시력 테스트("서비스")는 회원가입이 없으며, 이름·이메일·전화번호 등 신원 정보를 수집하지 않습니다. 다만 기능 이용 과정에서 다음 정보가 처리될 수 있습니다.

  • 사진 분석(기본): 업로드한 사진은 브라우저 내에서만 분석되며 서버에 저장되지 않습니다.
  • 주간 랭킹 등록(선택): 사용자가 직접 등록하는 경우에 한해 — 업로드 사진, 닉네임, 분석 점수(원시인/현대인 %), 등록 시각, 주차 정보가 서버에 저장됩니다.
  • 자동 수집: 쿠키 및 익명 분석 데이터 (아래 4·5항 참조)

2. 사진 데이터 처리 방식

  • 기본 분석은 사용자 기기의 브라우저 내에서만 이루어지며, 사진이 서버로 전송되지 않습니다. 페이지를 닫으면 사진 데이터는 소멸됩니다.
  • 사용자가 결과 화면에서 "이번 주 랭킹에 도전하기"로 직접 등록한 경우에 한해, 그 사진이 서버에 업로드·저장되어 공개 랭킹에 표시됩니다.
  • 랭킹에 등록된 사진·닉네임은 해당 주가 끝나면 자동으로 삭제됩니다.
  • 랭킹에 등록하지 않으면 사진은 서버에 저장되지 않습니다.
  • 분석 결과 이미지를 저장하는 경우, 해당 이미지는 사용자의 기기에만 저장됩니다.

3. 주간 랭킹 기능과 공개 게시

주간 랭킹은 선택적 기능으로, 사용자가 직접 등록할 때만 동작합니다.

  • 저장 항목: 사진, 닉네임, 점수, 주차 정보
  • 공개 범위: 등록된 사진과 닉네임은 누구나 볼 수 있는 공개 랭킹에 표시됩니다.
  • 보관 기간: 해당 주차 종료 시 자동 삭제됩니다. 그 전에 삭제를 원하시면 아래 문의 이메일로 요청해 주세요.
  • 저장 위치: 데이터는 Cloudflare의 데이터베이스(D1)와 스토리지(R2)에 저장되며, 국외 서버에 저장·처리될 수 있습니다.
  • 이용자 책임: 본인 사진 또는 사용 권리가 있는 사진만 등록해야 하며, 타인의 사진을 동의 없이 등록해서는 안 됩니다.

4. 쿠키(Cookie) 및 광고

본 서비스는 Google AdSense를 통해 광고를 게재합니다. Google AdSense는 맞춤형 광고 제공을 위해 쿠키를 사용할 수 있습니다.

  • Google 쿠키: Google은 쿠키를 사용하여 사용자의 관심사에 맞는 광고를 표시할 수 있습니다.
  • DoubleClick 쿠키: 광고 효과 측정 및 광고 남용 방지를 위해 사용됩니다.
  • 사용자는 Google 광고 설정에서 맞춤형 광고를 비활성화할 수 있습니다.
  • 또는 aboutads.info에서 제3자 쿠키를 관리할 수 있습니다.

Google의 데이터 사용 방식에 대한 자세한 내용은 Google 광고 개인정보 보호정책을 참조하시기 바랍니다.

5. 웹 분석 (Google Analytics, Microsoft Clarity)

서비스는 사용자 경험 개선을 위해 다음 분석 도구를 사용합니다.

  • Google Analytics 4: 방문자 수, 페이지 조회수, 사용 패턴 등 익명화된 통계 데이터를 수집합니다. 이 데이터는 특정 개인을 식별하지 않습니다.
  • Microsoft Clarity: 사용자의 클릭 패턴, 스크롤 행동 등 익명 행동 분석 데이터를 수집합니다.

두 도구 모두 IP 주소를 익명화하여 처리하며, 수집된 데이터는 개인을 식별하는 데 사용되지 않습니다.

6. 처리 위탁 및 제3자 제공

서비스는 운영을 위해 아래 사업자의 인프라·도구를 이용하며, 이 범위에서 데이터가 처리·저장될 수 있습니다.

  • Cloudflare: 사이트 호스팅 및 주간 랭킹 데이터·사진 저장 (국외 서버 포함)
  • Google: AdSense 광고 게재 및 Analytics 분석
  • Microsoft: Clarity 행동 분석

위 목적 외에는 이용자의 정보를 제3자에게 판매하거나 제공하지 않습니다. 또한 서비스에 포함된 외부 사이트 링크의 개인정보 처리에 대해서는 제공자가 책임지지 않습니다.

7. 아동의 개인정보 보호

본 서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다. 만 14세 미만은 보호자의 지도 하에 서비스를 이용하시기 바랍니다.

8. 이용자의 권리

사용자는 언제든지 다음의 권리를 행사할 수 있습니다.

  • 주간 랭킹에 등록한 사진·닉네임의 삭제 요청 (아래 문의 이메일로 요청 시 처리)
  • 개인정보 처리 정지 요청
  • 쿠키 삭제 (브라우저 설정에서 직접 삭제 가능)

랭킹에 등록하지 않은 경우 별도로 저장되는 개인 식별 정보가 없으므로, 대부분의 데이터는 브라우저 설정에서 직접 관리하실 수 있습니다.

9. 개인정보처리방침의 변경

본 방침이 변경될 경우, 변경 사항을 이 페이지에 공지하며 시행일을 명시합니다. 중요한 변경이 있을 경우 서비스 메인 페이지에 별도 공지합니다.
